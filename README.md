# LUMEN — Drone Show

Three.jsによる、文字・絵文字を描く単一HTMLのドローンショーです。

公開ページ: https://kagoya.github.io/droneshow/

## 使い方

`index.html` をブラウザで開きます。ネット接続やサーバーは不要です。

- 最大10文字を入力し「ショーを作成」で開始
- 光点数は200・500・1000から選択（変更するとショーを再構成）
- 絵文字の元の配色を各点に反映
- 「周回カラーモード」をオンにすると、通常の文字が周回ごとに単色・グラデーション・虹色へ変化。絵文字は元の配色を維持
- 各文字を順番に表示し、立体回転・移動・展開で切り替え
- 光点の位置・色・明るさが緩やかに変化。輪郭を少し明るく表示
- 映像をクリックして全画面表示。再クリックまたはEscで終了
- BGMチェックボックスでオリジナルの72秒ループ曲をオン・オフ
- 「最初から」で映像とBGMを先頭に戻す

絵文字の形や色は端末のフォントに依存します。WebGLとWeb Audioに対応したブラウザが必要です。
